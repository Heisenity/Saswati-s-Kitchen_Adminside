# Saswati's Kitchen Admin — UI/UX Guidelines

Avoid decorative motion that slows operations.

---

# 44. Visual Quality Checklist

Before considering a page finished, verify:

```text
Is hierarchy obvious?

Can the primary action be found immediately?

Is information too spread out?

Are statuses consistent?

Are destructive actions safe?

Is there a loading state?

Is there an empty state?

Is there an error state?

Is keyboard interaction usable?

Does it still feel like Saswati's Kitchen
without looking like a marketing website?
```

---

# 45. Anti-Patterns

Avoid:

```text
giant KPI cards
five gradients on one page
random neon colors
glassmorphism everywhere
huge hero sections
food photos inside operational order tables
inconsistent badges
every page having a different card style
arbitrary button colors
fake analytics
fake charts presented as real data
```

---

# 46. Admin Design Goal

The desired visual impression is:

```text
Professional
Modern
Compact
Premium
Operational
Trustworthy
Fast
```

Not:

```text
Template-heavy
AI-generated
Decorative
Over-designed
Consumer-style
```
